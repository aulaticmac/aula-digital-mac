¿Cómo se obtienen las sustancias?

Aprende a reconocer y clasificar cuatro tipos de reacciones químicas.

Síntesis o combinación

Dos o más reactivos se combinan para formar un solo producto principal.

A + B → AB
2Mg + O₂ → 2MgO

Pista: varios reactivos forman un producto.

Partículas: 🔵 + 🟡 → 🔵🟡

Descomposición o análisis

Un solo reactivo se transforma en dos o más productos. Puede requerir calor, luz o electricidad.

AB → A + B
2KClO₃ —Δ→ 2KCl + 3O₂

Pista: un reactivo origina varios productos.

Partículas: 🔵🟡 → 🔵 + 🟡

Sustitución o desplazamiento simple

Un elemento libre desplaza a otro elemento de un compuesto. La reacción depende de la reactividad de los elementos.

A + BC → AC + B
Zn + 2HCl → ZnCl₂ + H₂

Pista: elemento + compuesto producen compuesto + elemento.

Partículas: 🔴 + 🔵🟡 → 🔴🟡 + 🔵

Doble sustitución o intercambio

Dos compuestos intercambian iones. Suele formarse un precipitado, un gas o una sustancia poco ionizada como el agua.

AB + CD → AD + CB
AgNO₃ + NaCl → AgCl↓ + NaNO₃

Pista: compuesto + compuesto producen dos compuestos.

Partículas: 🔵🟡 + 🔴🟢 → 🔵🟢 + 🔴🟡
