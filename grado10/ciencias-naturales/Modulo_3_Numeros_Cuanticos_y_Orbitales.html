Ficha de estudio

1. Los cuatro números cuánticos

n

Principal

Valores: 1, 2, 3…

Indica el nivel principal de energía. Al aumentar n, generalmente aumenta el tamaño y la energía del orbital.

l

Secundario

Valores: 0 hasta n − 1

Identifica el subnivel y se relaciona con la forma del orbital.

ml

Magnético

Valores: −l hasta +l

Distingue los orbitales dentro de un mismo subnivel.

ms

Espín

Valores: +½ o −½

Distingue las dos orientaciones de espín permitidas para un electrón.

Orden de validación: comprueba primero n, después l, luego ml y finalmente ms. Cada restricción depende de la anterior.

No confundas orbital con órbita: un orbital es una región descrita por una función de probabilidad. No representa una trayectoria circular fija del electrón alrededor del núcleo.

3. Ejemplo de validación

Conjunto válido

(n, l, mₗ, mₛ) = (3, 2, −1, +½)

Para n = 3, l puede ser 0, 1 o 2. Si l = 2, ml puede ir de −2 a +2. El espín +½ es permitido.

Conjunto inválido

(2, 2, 0, +½)

Para n = 2, l solo puede ser 0 o 1. El valor l = 2 viola la regla l ≤ n − 1.

Errores frecuentes

Detecta y corrige

“Para n = 3, l puede valer 3”.

Incorrecto. l toma valores desde 0 hasta n − 1. Para n = 3: l = 0, 1 o 2.

“Un subnivel p tiene dos orbitales porque su forma tiene dos lóbulos”.

Incorrecto. Los lóbulos de una representación no equivalen al número de orbitales. Un subnivel p tiene tres orbitales, correspondientes a ml = −1, 0 y +1.

“mₗ siempre es positivo”.

Incorrecto. ml toma todos los enteros desde −l hasta +l, incluido cero.

“mₛ puede ser 0”.

Incorrecto. Para un electrón, ms solo puede ser +½ o −½.
